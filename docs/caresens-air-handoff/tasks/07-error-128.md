## Confirmed revised-current rules

All thresholds, gates and edge cases below were established by controlled
black-box state perturbation (`err128_revised_current_probe.py --perturbations`)
and verified bit-for-bit against vendor state snapshots.

- **Rejection invariance.** Rejected records (`data_type == 2` or error 64) leave
  all four `err128_*` state fields unchanged (verified on seed 202 run 127,
  sequence 2376).
- **Activation gate.** On every accepted record, the stage checks:
  - `idx >= 36` (at least 36 prior accepted records before incrementing `idx`;
    `35 → 0`, `36 → 1` on both onset and persistence), and
  - **pre-record** `diabetes_before_7days_flag` in `{0, 1, 2}` (`{0, 1, 2} → 1`,
    `{3, 4, 5, 6, 100} → 0`). On sequence 864 (flag `100 → 0`) the stage is
    still disabled; on sequence 2017 (`0 → 6`) it is still enabled.
  - When either gate fails, `err128_flag = 0`, `err128_normal = NaN`, and
    `err128_revised_value = tran_inA_5min` (`curr_avg_arr[-1]`).
- **Persistence and recovery (`err128_flag_prev[39] == 1`).** While active,
  revision persists (`err128_flag = 1`, keeping `err128_normal_prev` and
  `err128_revised_value_prev`) if and only if:
  1. `err128_flag_prev[4] == 0` (the record 36 accepted records earlier was not
     flagged — caps a continuous run at 36 accepted records, and also terminates
     a new run if slot 4 still holds an earlier active flag, as in seed 101 run
     16 at sequence 2270);
  2. `|seq - accu_seq[-1]| <= 3` (`-4 → 0`, `-3..3 → 1`, `4 → 0`);
  3. Rounded current glucose `g = round(result_glucose)` has not recovered:
     `!(g >= 80.0 || g >= err128_normal_prev)`. When `err128_normal_prev` or `g`
     is `NaN`, only a finite `g >= 80` clears it.
  - Failure of persistence does not fall through to onset on the same record; it
    clears to `err128_flag = 0`, `err128_normal = NaN`,
    `err128_revised_value = tran_inA_5min`.
- **Onset (`err128_flag_prev[39] == 0`).** Using the 11 preceding accepted
  records (`accu_seq[-11..-1]`, `err_glu_arr[-11..-1]`,
  `time_standard_arr[-11..-1]`) and current `(seq, time, g = round(result_glucose))`,
  revision activates (`err128_flag = 1`, `err128_normal = err_glu_arr[-1]`,
  `err128_revised_value = err128_revised_value_prev`) if and only if:
  1. **Sequence continuity:** `accu_seq[-11] != 0` and `1 <= seq - accu_seq[-11] <= 11`;
  2. **Pre-drop ceiling:** none of the 11 prior rounded glucoses exceeds `120.0`
     (`!(err_glu_arr[k] > 120.0)`);
  3. **Pre-drop stability:** among the 10 consecutive intervals between those 11
     prior records, at least 9 have `dt != 0` (32-bit unsigned difference in
     seconds) and `|(g[k+1] - g[k]) / (dt / 60.0)| < 0.8` mg/dL/min (strict);
  4. **Sharp drop:** `cur_dt = (time - time_standard_arr[-1]) & 0xffffffff != 0`
     and `(g - err_glu_arr[-1]) / (cur_dt / 60.0) < -2.5` mg/dL/min (strict).
  - Onset can trigger on `data_type == 0` (e.g. takeover seed 7 run 12,
    sequence 4037) and persistence continues across `data_type == 0` (e.g. fresh
    seed 101 run 61, sequence 1603).
- **State update.** On every accepted record (including `idx < 36`),
  `err128_flag_prev[40]` shifts left by 1 and appends `err128_flag` (even across
  sequence gaps), `err128_normal_prev = err128_normal`,
  `err128_revised_value_prev = err128_revised_value`, and
  `err128_CGM_c_noise_revised_value[36]` shifts left by 1 and appends
  `err128_revised_value`.
- **State offsets** (from `tools/caresens-oracle/research/state-offsets.txt`):

- **Device block.** Perturbing `cal_noise`, `errcode_version` and
